Before you start

This tool talks directly to CAN bus hardware. On a live burner control system it can, if put into Keep alive mode, transmit onto a safety-relevant bus. Use Listen only (selected below by default) on any bus you do not own or fully understand -- a plant line, a burner that is not isolated from fuel and ignition. Only use Keep alive on a bench that is de-fuelled, de-ignited, and mechanically isolated.
